型から強くなる。

吉岡小タイピング道場は、正しい指づかいから鍛える道場スタイルのタイピング学習サイトです。はじめのいっぽから黒帯まで、段位表にそって着実に上達しよう。

小学１・２年生 ローマ字入力がまだ分からない人はじっくりコースを選んで、タイピングのポイントをつかもう タイピングの達人をめざすひと ブラインドタッチを身につけたい人はぐんぐん達人コースを選ぼう

段位表

２つのコースのトレーニングルームで黒帯をとるまで鍛える

　じっくりコースとぐんぐん達人コースを選んだら、それぞれのトレーニングルームで練習をくりかえそう。最後は「黒帯昇段試験」にチャレンジしてみよう！

コース選択

　キーボードにまだ慣れていない１・２年生向け。あ・い・う・え・お　から れんしゅうを始めます。

はじめのいっぽ — しょしんしゃのおび

ローマ字、さいしょの一歩

　「あ・い・う・え・お」の5つの母音だけを、ゆっくり正確に打つ。キーボードに慣れるための、いちばんはじめの練習。

あいうえお
トレーニングをはじめる →
かきくけこ の練習

子音と母音を組み合わせる

　子音の「K」に、あいうえおを組み合わせると「かきくけこ」になる。ローマ字入力のしくみを学ぶ練習。

かきくけこ
トレーニングをはじめる →
さしすせそ の練習

もうひとつの子音を覚える

　子音の「S」に、あいうえおを組み合わせると「さしすせそ」になる。ことばの練習も加わるよ。

さしすせそ
トレーニングをはじめる →
たちつてと の練習

3つめの子音を覚える

　子音の「T」に、あいうえおを組み合わせると「たちつてと」になる。ことばの練習も加わるよ。

たちつてと
トレーニングをはじめる →
なにぬねの の練習

4つめの子音を覚える

　子音の「N」に、あいうえおを組み合わせると「なにぬねの」になる。ことばの練習も加わるよ。

なにぬねの
トレーニングをはじめる →
はひふへほ の練習

5つめの子音を覚える

　子音の「H」に、あいうえおを組み合わせると「はひふへほ」になる。ことばの練習も加わるよ。

はひふへほ
トレーニングをはじめる →
まみむめも の練習

6つめの子音を覚える

　子音の「M」に、あいうえおを組み合わせると「まみむめも」になる。ことばの練習も加わるよ。

まみむめも
トレーニングをはじめる →
やゆよ の練習

7つめの子音を覚える

　子音の「Y」に、「あ・う・お」を組み合わせると「やゆよ」になる。ことばの練習も加わるよ。

やゆよ
トレーニングをはじめる →
らりるれろ の練習

8つめの子音を覚える

　子音の「R」に、あいうえおを組み合わせると「らりるれろ」になる。ことばの練習も加わるよ。

らりるれろ
トレーニングをはじめる →
わをん の練習

ひらがなの基本、ラストの3文字

　「わ」「を」は子音「W」、「ん」は「N」を2回打つ特別な文字。これでひらがなの基本（清音）が全部そろうよ。

わをん
トレーニングをはじめる →
が行（濁音）の練習

「゛」で音が変わる、濁音を覚える

　か行の「K」を「G」に変えるだけ。「がぎぐげご」を練習しよう。

が行
トレーニングをはじめる →
ざ行（濁音）の練習

さ行に濁音がついた音を覚える

　さ行の「S」を「Z」に変えるだけ。「ざじずぜぞ」を練習しよう。

ざ行
トレーニングをはじめる →
だ行（濁音）の練習

た行に濁音がついた音を覚える

　た行の「T」を「D」に変えるだけ。「だぢづでど」を練習しよう。「ぢ」は「DI」、「づ」は「DU」で打つよ。

だ行
トレーニングをはじめる →
ば行・ぱ行（濁音・半濁音）の練習

「゛」と「゜」で音が変わる

　は行の「H」を「B」に変えると「ばびぶべぼ」、「P」に変えると「ぱぴぷぺぽ」。ふたつをまとめて練習しよう。

ば行・ぱ行
トレーニングをはじめる →
清音の拗音（ようおん）の練習

小さい「ゃゅょ」がつく音

　「きゃ」「しゅ」「りょ」は、い段の子音と母音のあいだに「Y」をはさむだけ。新しく覚えるキーはひとつもないよ。

清音の拗音
トレーニングをはじめる →
ガ・ザ・ダ行の拗音（ようおん）の練習

「ぎゃ」「じゅ」「ぢょ」も同じきまり

　濁点のついた「ぎ・じ・ぢ」にも小さい「ゃゅょ」がつくよ。きまりは清音の拗音とまったく同じ。

ガ・ザ・ダ行の拗音
トレーニングをはじめる →
バ・パ行の拗音（ようおん）の練習

「びゃ」「ぴょ」で、ひらがながぜんぶそろう

　半濁点・濁点のついた「び・ぴ」にも小さい「ゃゅょ」がつくよ。これを覚えると、ひらがなの音がぜんぶそろう。

バ・パ行の拗音
トレーニングをはじめる →

基本の構え

まなびかた

むずかしい準備はいらない

入門したら、すぐに白帯の間で型稽古をはじめられる。

01

じぶんの道着を選ぶ

なまえとキャラクターを選ぶだけ。むずかしい登録項目はなし。

02

ホームポジションに指をおく

F・Jの小さな凸（でっぱり）を目印に、正しい構えから始める。

03

型稽古をかさねて帯をのぼる

短い練習を積み重ねて、つぎの帯に挑戦する。
